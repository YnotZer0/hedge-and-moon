HEDGE & MOON - how to put it online (free, about 5 minutes)

1. GitHub Page

It’s free, run by Microsoft, and very stable, so the address will last for years. You do everything in a web browser with no coding. [Likely]

Make a free account at github.com.
Tap + → New repository. Name it hedge-and-moon, set it to Public, and tap Create repository.
Tap “uploading an existing file”. Unzip hedge-and-moon-app.zip and drag in the files inside the folder, not the folder itself. That’s index.html, sw.js, manifest.webmanifest and the three .png icons. Then tap Commit changes.
Go to Settings → Pages. Set Source to “Deploy from a branch”, choose branch main and folder / (root), then tap Save.
After a minute or two, your app is at https://YOURNAME.github.io/hedge-and-moon/.
